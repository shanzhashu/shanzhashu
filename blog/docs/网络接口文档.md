# 网络接口文档

- 基础路径：`https://<your-domain>/php/`
- 所有接口返回 `Content-Type: text/json`
- 鉴权方式：所有接口（除 GPT 接口外）均需传入 `session` 参数，值为用户的鉴权密钥（对应数据库 `my_user.f_key`）

---

## 1. 获取内容列表

**接口地址：** `GET /index.php`

**功能：** 获取当前用户的短博客列表。支持两种模式：

- **普通模式**（不传 `msgid`）：分页获取列表，支持关键词搜索
- **定位模式**（传入 `msgid`）：以指定消息为中心，返回其前后各最多 5 条记录，共最多 11 条；此时忽略 `page` 和 `query` 参数

**请求参数（Query String）：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| session | string | 是 | 用户鉴权密钥 |
| msgid | integer | 否 | 目标消息 ID（传入后进入定位模式） |
| page | integer | 否 | 【普通模式】页码，从 0 开始，每页 25 条，默认为 0 |
| query | string | 否 | 【普通模式】搜索关键词，对内容正文进行模糊匹配 |

**请求示例（普通模式）：**
```
GET /index.php?session=abc123&page=0&query=关键词
```

**请求示例（定位模式）：**
```
GET /index.php?session=abc123&msgid=101
```

**响应格式：** JSON 数组，按时间降序排列

**响应示例：**
```json
[
  {
    "f_id": "103",
    "f_time": "2024-01-16 12:00:00",
    "f_content": "更新的内容"
  },
  {
    "f_id": "101",
    "f_time": "2024-01-15 10:30:00",
    "f_content": "目标消息"
  },
  {
    "f_id": "99",
    "f_time": "2024-01-14 09:00:00",
    "f_content": "更早的内容"
  }
]
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|---|---|---|
| f_id | string | 内容唯一ID |
| f_time | string | 发布时间，格式 `YYYY-MM-DD HH:MM:SS` |
| f_content | string | 内容正文 |

**错误响应（纯文本）：**

| 返回内容 | 说明 |
|---|---|
| `Query No Result.` | session 无效，未找到对应用户 |
| `Auth Failed.` | 用户名获取失败 |
| `Record Not Found.` | 【定位模式】指定的 msgid 不存在 |
| `Query Content Error.` | 数据库查询异常 |

## 2. 发布内容

**接口地址：** `POST /post.php`

**功能：** 以当前用户身份发布一条新内容。

**请求参数：**

`session` 可通过 Query String 或 POST body 传入，`content` 必须通过 POST body 传入。

| 参数名 | 传参方式 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| session | Query String 或 POST body | string | 是 | 用户鉴权密钥 |
| content | POST body | string | 是 | 要发布的内容，最长 280 字符 |

**请求示例：**
```
POST /post.php?session=abc123
Content-Type: application/x-www-form-urlencoded

content=今天发布一条新内容
```

**响应示例（成功）：**
```
Success
```

**错误响应（纯文本）：**

| 返回内容 | 说明 |
|---|---|
| `Query No Session.` | 未提供 session 参数 |
| `Query No Result.` | session 无效，未找到对应用户 |
| `Auth Failed.` | 用户名获取失败 |
| `No Content.` | content 参数为空 |
| `Query Content Error.` | 数据库写入异常 |

## 3. 删除内容

**接口地址：** `GET /delete.php`

**功能：** 删除当前用户的指定内容，只能删除自己发布的内容。

**请求参数（Query String）：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| session | string | 是 | 用户鉴权密钥 |
| delid | string | 是 | 要删除的内容 ID（对应 `f_id`） |

**请求示例：**
```
GET /delete.php?session=abc123&delid=101
```

**响应示例（成功）：**
```
Success
```

**错误响应（纯文本）：**

| 返回内容 | 说明 |
|---|---|
| `Nothing to Delete.` | 未提供 delid 参数 |
| `Query No Result.` | session 无效，未找到对应用户 |
| `Auth Failed.` | 用户名获取失败 |
| `Delete Content Error.` | 数据库删除异常 |

> 注意：删除操作会同时校验 `f_name`，用户只能删除自己发布的内容，无法删除他人内容。

## 4. GPT 对话代理

**接口地址：** `POST /gpt.php`

**功能：** 将用户输入的 prompt 转发至 OpenAI GPT-3.5-turbo 接口，并将结果原样返回给客户端。

**跨域支持：** 是（`Access-Control-Allow-Origin: *`）

**请求格式：** `Content-Type: application/json`

**请求参数（JSON Body）：**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| prompt | string | 是 | 发送给 GPT 的问题或指令 |

**请求示例：**
```
POST /gpt.php
Content-Type: application/json

{
  "prompt": "用一句话介绍一下自己"
}
```

**响应格式：** OpenAI API 原始响应（JSON）

**响应示例：**
```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "我是一个由 OpenAI 训练的 AI 助手。"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 20,
    "completion_tokens": 18,
    "total_tokens": 38
  }
}
```

**GPT 调用参数说明：**

| 参数 | 值 | 说明 |
|---|---|---|
| model | gpt-3.5-turbo | 使用的模型 |
| max_tokens | 3000 | 最大返回 token 数 |
| temperature | 0.5 | 生成随机性，0~1 |

> 注意：此接口不需要 session 鉴权，但依赖服务端配置的 OpenAI API Key，请勿在客户端直接暴露。

## 通用说明

### 鉴权流程

所有需要鉴权的接口，服务端处理逻辑如下：

1. 从请求参数中取出 `session`
2. 查询 `my_user` 表，匹配 `f_key = session`
3. 获取对应的 `f_name` 作为当前用户身份
4. 后续数据操作均以该 `f_name` 为范围，保证数据隔离

### 特殊字符处理

服务端会对 `session`、`query`、`content` 等参数中的单引号（`'`）和双引号（`"`）进行过滤替换为空格，客户端传参时应避免依赖这些字符。
